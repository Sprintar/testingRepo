**Features Released**
- Agent Cover Image
  - Users can now toggle the display of agent cover images on or off at the user level, ensuring a consistent and customizable layout for agent cards. When enabled, agent cards display user-provided images or a default fallback image. When disabled, all cover images are hidden, providing a simplified interface. This setting applies across all views and environments.
- Export Agent Messages to Word
  - Users can now select specific agent messages and export them to a Word document while maintaining the original chat format. This feature supports all chat types and allows for greater control over exported content.

**Additional Enhancements**
- The application footer now supports displaying both the Accenture logo and a client-provided logo, offering flexible branding options. Users can choose to display both logos, only one, or none, with a default fallback to the Accenture logo.
- Release notes are now accessible via a public URL, allowing users to view release details directly from the application interface. A dedicated section lists all release notes, with links to individual release files for easy access.
- The agent chat box has been improved to be larger and responsive, adapting dynamically to the available screen space for an enhanced user experience.
