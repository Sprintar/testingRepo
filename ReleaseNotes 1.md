# Sprint 1  
Release Date: 25 Aug 2025  

## Features Released:  
- **Add Import/Export Feature for All Entities** - Introduced import/export functionality for all entities via the backend API.  
- **Add Support for Wolfram Alpha Function Tools** - Added integration with Wolfram Alpha function tools for enhanced computational capabilities.  
- **Agent Handoffs Stop Workflow Execution** - Implemented functionality to halt workflow execution during agent handoffs.
