**Features Released**
- Clone Entities - Agent
   - Users can now clone agents and their related entities by value or reference, enabling independent operation. The cloning process includes datasets (by reference), system instructions, and templates, with clear UI previews outlining what will be cloned and any associated limitations. Editable agent names and detailed notes ensure clarity during the cloning process.

**Additional Enhancements**
- Users can preview cloning details in a user-friendly interface.
   - The UI now provides a preview of all items to be cloned, including datasets, system prompts, and templates, with clear notes on ownership and references. Errors in retrieving agent or clone data are handled gracefully.
