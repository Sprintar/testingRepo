**Features Released**
- Agent Cover Image
   - Users can now toggle the visibility of agent card cover images to ensure a consistent and professional layout. When enabled, agent cards display user-provided or default fallback images; when disabled, all cover images are hidden for a simplified interface. This preference is configurable per user and environment.
- Export Agent Messages to Word
   - Users can select specific agent responses and export them to a Word document while maintaining the original chat format. This feature supports all chat types and ensures precise control over exported content.

**Additional Enhancements**
- The footer now supports flexible branding options.
   - Users can configure the footer to display both the Accenture logo and a client logo, only one logo, or no logos at all. When both logos are displayed, they are separated by a vertical bar for a clean and consistent presentation.
- Release notes are now accessible via a public URL.
   - Release notes are generated at the end of each sprint and made available through a public Git repository. Users can view and navigate release notes directly from the application interface.
- The agent chat box is now larger and responsive.
   - The chat box dynamically adjusts to the available screen space, improving readability and user experience.
